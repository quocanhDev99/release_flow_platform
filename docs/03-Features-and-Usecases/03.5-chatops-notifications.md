# ChatOps & Notifications

## 1. Feature Overview
The ChatOps feature bridges the Release Flow Platform with team communication tools (Telegram, Email, MS Teams, Slack). It broadcasts real-time alerts whenever a significant event occurs, such as a deployment schedule being created, updated, or an AI OCR import completing. It supports both Global/System-wide broadcasts, Automated Daily Reminders, and User Mentions (`@username` / MS Teams `<at>username</at>`).

---

## 2. Key Features
- **Multi-Channel Delivery**: Instant broadcast across Telegram, Slack, MS Teams, and Email.
- **Native User Mentions**: Resolves developer usernames to format HTML/Text `@username` for Telegram/Slack and constructs AdaptiveCard `msteams.entities` `<at>username</at>` targeting `user.email` for MS Teams push notifications.
- **Event-Driven & Scheduled Alerts**: Supports real-time triggers (schedule create/update) and scheduled cron reminders (08:00 AM today's deployments & 16:30 PM tomorrow's warnings).

## 4. Sequence Diagram (Event-Driven & Scheduled Notification)

```mermaid
sequenceDiagram
    autonumber
    actor User as Release Manager / System
    participant API as NestJS API / CronService
    participant NotifSvc as Notification Service
    participant Config as Settings Config
    participant External as Teams / Slack / Telegram / Email

    User->>API: Event Trigger or Scheduled Cron Job
    API->>NotifSvc: Call sendScheduleAlert() / sendDailyReminder()
    NotifSvc->>Config: Get Webhooks, Tokens & User Email
    Config-->>NotifSvc: Return configurations & user info
    
    NotifSvc->>NotifSvc: Build Adaptive Cards with <at>username</at> entities
    
    par Send to all channels
        NotifSvc->>External: POST /webhook (Slack)
        NotifSvc->>External: POST /webhook (MS Teams + Mention Card)
        NotifSvc->>External: POST /bot{token}/sendMessage (Telegram)
        NotifSvc->>External: SMTP sendMail (Email)
    end
    
    External-->>NotifSvc: HTTP 200 OK
    NotifSvc->>NotifSvc: Log Success
```
